W3BS OS server

w3bs.

This server runs W3BS OS.

W3BS OS is a lightweight Alpine Linux based operating system for servers, desktops and agents, with the w3bs package manager, zsh, Caddy, mise and the Profullstack tools installed. This is its default page: the owner has not published a site here yet.

Common commands

Find and install software

Signed packages from the W3BS repository.

w3bs search <name>
w3bs install <name>
w3bs list

Keep it up to date

Everything installed with w3bs, then the OS.

w3bs update --all
sudo w3bs os update

Administer

Administrators use sudo (or doas).

sudo <command>
sudo -i            # a root shell
sudo rc-service caddy reload

Developer tools

mise manages the runtimes; pnpm and bun are ready.

mise use -g node@lts python@3
pnpm i -g <package>
bun --version

Your own page

Every account gets a page and dev app hosting.

~/public_html/index.html   # /~you
~/apps/<name>/public/       # <name>.you.this-domain

A site of your own

One file per site; Caddy gets the HTTPS certificate.

sudo vi /etc/caddy/conf.d/example.com.caddy
#   example.com {
#     reverse_proxy 127.0.0.1:3000
#   }
sudo rc-service caddy reload
